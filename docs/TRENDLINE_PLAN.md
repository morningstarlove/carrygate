## 0. 한 줄 결론

**작도는 코드로 완전히 옮겨졌다(`trendline.py`). "하단에서 사서 상단에서 판다"를 실데이터 15종목 691건에 돌리면 수수료 뒤 건당 +1.13%(승률 32%, PF 1.40)로 플러스지만, t +2.17 로 이 저장소 기준(t > 3)에 못 미치고 같은 일수 그냥 들고 있는 것보다 건당 0.85% 낮다.** 바로 실거래할 근거는 아니다. 권고: 순방향 종이 기록(선택지 A) → 20건 판정 → 합격 때만 소액 실거래.

## 1. 자료의 말 → 고정 규칙 (결과 보기 전에 정함, `RULE_FIXED` 2026-11-17)

| 강의 자료 | 코드 (`trendline.py`) |
|---|---|
| 초점은 캔들의 최외각(꼬리) | 저가·고가로 긋는다(종가 아님) |
| 항상 오늘을 기준으로, 기간에 따라 대·중·소 | 오늘까지의 최근 N봉. 소 60 / 중 120 / 대 250 일봉 |
| 상향은 하단(저점-저점)부터 | ① = N봉 안 최저 저가. ② = ① 뒤 **확정 저점**(좌우 5봉 중 최저) 가운데 ①과 이은 기울기가 가장 작은 것 = 그 아래 저점이 없는 최외각 선. 기울기 > 0 이어야 상향. ①~② 간격 ≥ N/4 |
| ③고점에 평행하게 → 상단 | ①~② 사이에서 (고가 − 하단선) 이 가장 큰 봉이 ③. 그 거리가 채널 폭 W |
| 1:1 로 중단 | 하단 + W/2 |
| 두 점 기간의 향후 1배 유효 | ② 뒤 (②−①) 봉까지만 유효. 지나면 새 진입 없음 |
| 살짝 튀어나간 것은 '보조' | 하단 − 0.10×W 까지는 이탈로 안 본다 |
| 하향은 상단(고점-고점)부터, '파란 지붕' | `down_channel()` 거울상. 기록·표시만(매매 안 씀) |
| 하단에서 잡고 상단에서 놓는다 | **신호** 저가 ≤ 하단 + 0.10W · 종가 ≥ 하단 · 폭 ≥ 하단가의 5% → **다음 날 시가 매수**(선을 얼림) |
| 이탈하면 손절 | 종가 < 하단 − 0.10W → 다음 날 시가 |
| (자료에 없음, 우리가 정함) | 익절 = 고가가 상단에 닿으면 상단 가격. 만료 = 유효 기간 끝 날 종가. 한 종목·한 창에 한 포지션 |

비교 변형(함께 고정): `mid` 하단→중단 익절 · `midentry` 자료가 "손익비 반반"이라고 말린 중단 매수→상단. **사전 등록 주 규칙 = 중(120봉)·base.**
앞날을 미리 보지 않는다 — ②는 오른쪽 5봉이 지나야 저점으로 인정, 실데이터로 "앞쪽 봉만 줘도 같은 거래"를 시험한다(`test_no_lookahead_on_real_bars`).

## 3. 사실로 읽은 것

1. **9칸 모두 플러스, 9칸 모두 t < 3.** 방향은 한쪽이지만 우연과 구별되는 수준은 아니다.
2. **돈은 승률이 아니라 손익비에서 나온다.** 691건 중 하단 이탈 손절 549건(80%) 평균 −3.0%, 유효 기간 만료 93건(13%) 평균 +9.8%, 상단 익절 49건(7%) 평균 +31.5%. 작게 여러 번 잃고 드물게 크게 번다. 자료의 "하단을 닫아 놓고 공격적 접근"과 같은 모양.
3. **자료의 주장 확인:** "중단에서 잡으면 손익비 반반" — 중단 매수는 건당 +0.49% 로 하단 매수(+1.13%)의 절반 이하. 일치. "상단에서 놓는다" — 상단까지 가는 것은 7%(14번에 1번). 대부분은 선이 깨져서 나온다.
4. **선이 '사는 타이밍'의 우위를 준다는 근거는 없다.** 같은 일수 매수보유보다 낮다(금만 예외). 쓸모는 "시장에 있는 날을 줄이고 틀렸을 때 손실을 선으로 묶는 것".
5. **한국은 0.** 삼성전자·SK하이닉스·KOSDAQ 는 마이너스. 2010~2017 전체도 0.
6. 알려진 한계: ①이 창의 첫 봉(진짜 저점이 아닌 경계)이 될 수 있다 · 가격 축은 자료처럼 일반(로그 아님) · 종목 15개뿐 · 시험용 인공 봉에서 같은 기울기 동률을 "더 최근 저점"으로 고친 뒤 소 60봉 칸이 796→797건으로 1건 바뀜(주 규칙 숫자는 그대로).

## 4. 수익화 설계

| 단계 | 무엇 | 조건 |
|---|---|---|
| 1. 순방향 종이 기록 (선택지 A) | 매일 daily 에 "Trendline" 단계: 이미 받고 있는 일봉(한국 돌파 유니버스·코인 12종·미국 ETF)에 `trendline.py` 를 돌려 오늘 신호·종이 포지션을 `trendline.json`·`trendline_history.jsonl` 에 기록. 현황판 카드 "오늘 하단에 닿은 종목 + 하단·중단·상단 가격" | 사용자 결정 → `criteria.json` 봉인 + 잠금 + 판정 여덟 번째 트랙 |
| 2. 판정 (사전 등록안) | 시장군별 닫힌 거래 20건: 건당 순수익 > 0 **그리고** PF ≥ 1.3 → PASS / 건당 < 0 → FAIL / 그 사이 NOT_YET. 실력 0 이어도 PASS 할 확률을 함께 표시(기존 판정기 방식) | 규칙은 결과를 보고 고치지 않는다 |
| 3. 소액 실거래 | 합격한 시장군만, 별도 저장소 `carrygate-exec`. 1회 위험 = 계좌의 1% : 수량 = 계좌×1% ÷ (진입가 − 손절선). 주문은 다음 날 시가, 손절·익절은 선 가격 예약 | 2단계 PASS + 사용자 결정 |
| 4. 기존 트랙 보조 | 한국 돌파·터틀 진입 때 "채널 어디(하단/중단/상단)에서 샀나"를 기록만 해 두고, 위치별 성적이 갈리면 그때 제안 | 기록만, 규칙 변경 아님 |

보조 쓰임(바로 가능): `python -c "import trendline"` 의 `today(bars)` 가 어떤 일봉이든 오늘의 하단·중단·상단·'파란 지붕' 가격과 유효 기간을 낸다 — 사용자가 직접 차트에 그을 때 대조용.
