# P43 — P35 를 OKX 모의계좌로 2주 (설계서)

> 사용자 결정 2026-11-27 "a". 고정일 2026-11-27(모의 결과를 하나도 보기 전). 제안함 P43. 카드 `docs/cards/p43_exec_demo.svg`.

## 1. 왜
- P35(전날 18시장 되돌림 합 < 0 인 날만 30·60분 되돌림)는 11/26 순방향 14일 판단을 통과했다: 5일 써서 +329.0%(18시장 결과 합, 수수료 뺀 뒤), 5/5 플러스, 쉰 날 되돌림 −442.1%.
- 하지만 종이 기록은 ① 지정가는 가격이 **지나쳐야** 체결 ② 수수료 고정 ③ 주문 지연 0 이라는 가정 위에 있다. 돈을 넣기 전에 이 가정이 실제 주문 장부에서 얼마나 깎이는지 잰다.
- P41(11/25 첫 사용일): 2시간 늦게 시작하면 +4.5% → −4.0%. → **UTC 0시 정각 실행이 필수**라 사람 손이 아닌 서버 상주 프로그램으로 한다.

## 2. 무엇을 (새 규칙 없음)
- 코드: 별도 저장소 `carrygate-exec`(이 저장소엔 주문·키 코드 없음, 원칙 1). 이 저장소의 `scalp.py` 규칙 함수를 **그대로** 불러 쓴다.
- 대상: OKX 무기한선물 6코인(BTC·ETH·XRP·TRX·LINK·DOGE) × 30·60분 × {`vwap_fade_lim`, `mr_z20_lim`} = 24개. P35 18시장 중 OKX 몫만(업비트는 현물·공매도 불가, 하이퍼리퀴드는 모의계좌 없음).
- 판단: 매일 UTC 0시 직후 서버가 `scalp.py` 로 전날을 다시 계산 → 18시장 되돌림 합 < 0 이고 시장 ≥ 12 이면 오늘 씀. 결과 평가일이 전날이 아니면(묵은 파일) 쉼.
- 주문: 봉 마감 20초 뒤 OKX 확정 봉으로 신호 → 신호봉 종가에 **post_only 지정가**(메이커만). 3봉 안 미체결이면 취소. 청산 신호면 post_only 지정가 청산, 3봉 미체결·보유 한도면 시장가. UTC 0시에 남은 것 모두 정리.
- 크기: 1건 100 USDT(모의 돈). 최대 동시 24건.

## 3. 합격선 (사전 등록, 고치지 않는다)
모의 14일(설치 다음 UTC 날부터, 쓴 날만 센다):
1. 쓴 날 모의 순손익 합 > 0 (수수료 뺀 뒤)
2. 모의/종이 비율 ≥ 0.5 — 종이 = 같은 날 OKX 24개 결과 합(`paper_okx_net_pct_sum`), 쓴 날 합끼리 비교
3. 주문 오류·프로그램 중단으로 빠진 날 0일

셋 다면 **"소액 실거래 시험" 제안 자격**(새 제안 + 사용자 결정 필요, 자동 전환 없음). 하나라도 아니면 "종이 이익은 체결 가정 때문"으로 기록하고 P35 는 종이 기록만 계속.
쓴 날이 14일 안에 3일 미만이면 판단을 7일 미룬다(1회만).

## 4. 안전장치
- `x-simulated-trading: 1` 이 코드에 고정(`cgx/okx.py SIMULATED`). 실거래 전환은 코드 변경 + 이 문서 갱신 + 사용자 결정이 함께 있어야 한다.
- 키: OKX **모의거래** API 키, 권한 읽기+거래(출금 없음), IP 158.247.206.213 제한. 서버 `.env`(600)에만. 대화창·저장소에 붙여넣지 않는다.
- `STOP` 파일 → 15초 안에 전부 정리하고 멈춤. 하루 실현 손실 100 USDT 넘으면 그날 새 진입 중단.
- 매일 하루 합계만(키·주문번호 없음) 서버 웹 폴더 `/carrygate/exec_demo/latest.json` 으로. 매일 09:18 정기 실행의 `exec_demo.py` 가 읽어 `exec_demo_history.jsonl`(정해진 칸만)·`exec_demo.json`(누적·판정 WAIT/PASS/FAIL)에 기록 → 17:10 보고가 '모의 vs 종이' 한 줄. 설치 첫날처럼 UTC 0시 15분 뒤 시작한 날(`partial`)은 세지 않는다.

## 5. 알려진 차이 (재는 대상)
- 체결: 종이는 '지나쳐야', 실제는 '닿으면 줄 순서'. 추가 체결분은 대부분 불리한 쪽(역선택, P26·P29·P38 교훈)일 것으로 예측.
- 같은 봉 재진입: 종이는 청산·만료 봉에서 바로 재진입 가능, 실제는 봉이 닫혀야 알아 한 봉 늦음.
- 가짜 거래소 시험(인터넷 없이): 종이와 같은 체결 규칙이면 무작위 60경우 중 56경우 매매 완전 일치, 4경우는 위 재진입·자료 끝 처리 차이.
