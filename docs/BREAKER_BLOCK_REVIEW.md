## 0. 한 줄 결론

**8종목 × 2봉(4시간·1시간) 1,465건에서 카드 규칙의 성적은 "같은 손절폭·목표로 아무 봉에서나 들어간 것"과 똑같다(초과 +0.003R, t +0.07).** 수수료 뒤 건당 −0.105R(승률 35%)로 마이너스. 16개 종목·봉 중 기준선을 t > 3 으로 이긴 곳 0(최고 나스닥 1H t +1.24). 코인 4H 는 앞 절반 +0.15R → 뒤 절반 −0.17R 로 뒤집혔다. **트랙 신설 비추천.**

## 1. 카드가 말하는 것

1. 이전 고점 위로 올라가 매수 유동성(BSL)을 쓸어 담는다(스윕).
2. 강한 하락으로 이전 저점(HL)을 깬다 = Bearish MSS(구조 전환).
3. 스윕을 만든 상승의 출발점(Bullish OB)이 깨지면서 공급 구간(브레이커)으로 바뀐다.
4. 그 구간으로 되돌림이 오면 반응을 확인하고 숏. 손절은 되돌림 고점 위 또는 블록 상단.

카드에는 스윙의 정의, 시간 제한, "반응 확인"의 기준, **목표가**, 봉 주기, 대상 시장이 없다 → 아래에서 결과를 보기 전에 정했다.

## 2. 외부 근거 (2026-11-13 검색)

- 학술·독립 검증 **없음**. 결과는 전부 교육 페이지·지표 판매 페이지(LuxAlgo, TMGM, Backtrex, Plisio 등)이고 수익 주장은 표본 밖 통계가 없다.

## 3. 숫자로 고정한 것 (결과 보기 전, 스크립트 머리에 그대로)

| 카드 | 고정 규칙 |
|---|---|
| 고점·저점 | 좌우 3봉 프랙탈. 피벗 뒤 3봉이 닫혀야 "확인"(미래 정보 금지) |
| ① 스윕 | 새 스윙고점 H2 > 직전 스윙고점 H1. 둘 사이 가장 낮은 스윙저점 = HL |
| OB → ③ 브레이커 | H1~HL 사이에서 HL 쪽부터 찾은 마지막 음봉의 [저가, 고가] |
| ② MSS | H2 뒤 30봉 안에 종가 < HL 저가(그 전에 H2 위로 가면 무효) |
| ④ 진입 | MSS 뒤 40봉 안에 고가가 구간 하단에 닿고, 닿은 봉부터 10봉 안에 종가 < 구간 하단 → 다음 봉 시가 숏. 확인 전 종가 > 구간 상단 또는 고가 > H2 면 무효 |
| 손절 | max(구간 상단, 되돌림 최고가) |
| 목표 (카드 빈칸) | 2R. 50봉 지나면 종가 청산. 같은 봉에 손절·목표 둘 다면 손절 먼저 |
| 비용 (왕복) | 코인 0.12%(선물 시장가 0.05%×2 + 미끄러짐), 금·유로달러·나스닥 0.04% |
| 거울 | 가격을 뒤집어 같은 규칙 = 롱 브레이커(하단 스윕 → 상승 MSS → 되돌림 롱) |
| **기준선(잡음)** | 신호마다 같은 종목·방향·손절폭·목표·50봉으로 **무작위 봉 100곳**에서 진입한 평균 R. "카드 − 기준선"이 이 패턴만의 몫(상승장에서 숏이 지는 것, 손절폭에 대한 수수료 부담까지 빼 준다) |

변형(함께 고정): `touch` 확인 없이 구간 하단 지정가 · `tp1`/`tp3` 목표 1R/3R · `n5` 5봉 프랙탈.

자료: TradingView(2026-11-13). 바이낸스 현물 BTC·ETH·SOL·XRP·DOGE, OANDA 금, FX 유로달러, CME 나스닥 선물(NQ1!). 4시간봉 2023~24년 → 2026-11(약 3년), 1시간봉 2026-01 → 2026-11(약 10개월, 피드 한도).

## 5. 해석

- 승률 35% × 2R 은 수수료 전 손익분기(33%) 근처다. 그런데 **아무 데서나 같은 손절·목표로 들어가도 거의 같은 승률이 나온다** → 패턴이 방향을 맞히는 힘이 측정되지 않는다. 손익은 손절폭 대비 수수료 크기가 거의 다 결정한다(1시간봉일수록 손절이 좁아 수수료가 R 을 크게 깎는다).
- 그림 속 "깔끔한" 예는 고른 것이다. 같은 규칙이 실제로 낸 BTC 4H 연속 2건도 하나는 +2.15%, 하나는 −1.79%(카드 그림).
- `touch` 의 +0.058(t 1.75)은 첫 계산에서 t +6.35 였다. 닿은 봉의 종가를 보고 들어갈지 정하는 **미래 정보 누수**와, 체결 봉 안에서 체결 전 저가로 목표를 친 **봉 내부 순서 착시** 두 가지를 고치자 사라졌다. 이런 패턴 백테스트가 쉽게 부풀려지는 이유의 실례다.

## 6. 검증 한계

- 정의를 하나로 고정했다. "진짜 브레이커는 다르게 그린다"는 반론은 늘 가능하다 — 다만 변형 4개도 모두 기준선과 차이 없음.
- 1시간봉은 10개월뿐. 15분 이하 봉은 피드 깊이(2.5개월)가 짧아 뺐다.
- 바이낸스 현물 가격으로 선물 숏을 근사(펀딩비 미반영, 보유 평균 2일 미만이라 영향 작음).
- 백테스트 합격/불합격은 약한 근거(원칙). 여기서는 "없다" 쪽 근거이고, 결과를 보고 고른 조합(나스닥 1H 등)은 근거로 쓰지 않는다.
