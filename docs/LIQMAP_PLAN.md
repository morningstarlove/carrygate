# 청산 맵 비대칭 — 설계서 (제안함 P38)

> 2026-11-15 작성. **이 문서의 숫자는 선별(과거 자료 시험) 결과를 보기 전에 고정했다.** 결과를 보고 고치지 않는다(원칙 5).
> 계기: 사용자가 공유한 코인글래스 "청산 맵" 화면(BTC 67,194, 위쪽 숏 청산 누적 약 $4.0B vs 아래쪽 롱 청산 약 $0.9B).
> **결과(11/15): 근거 없음 — 트랙 신설 없음. 7절.**

## 1. 무엇을 알고 싶은가

"청산 물량이 많이 쌓인 쪽으로 가격이 끌려간다(자석 이론)"가 **수수료를 뺀 뒤에도** 맞는가.
코인글래스 화면은 실제 주문이 아니라 추정치이고, API 는 키가 필요해 이 저장소에 못 넣는다.
그래서 같은 원리의 추정 맵을 **공개 자료(미결제약정 + 가격)만으로 직접 계산**해서 잰다.

## 2. 추정 맵 계산 (모형 v1, 고정값)

재료: 무기한 선물 **1시간봉**(시·고·저·종가)과 같은 시각의 **미결제약정**(OI, 코인 개수).

| 이름 | 값 | 뜻 |
|---|---|---|
| `LOOKBACK_H` | 336 (14일) | 이보다 오래된 포지션 묶음은 버린다 |
| `LEVS` | 10·25·50·100배, 각 25% | 새 포지션의 레버리지 가정 (코인글래스 화면의 구분과 같음) |
| `MMR` | 0.5% | 유지증거금률 가정 |
| 진입가 | 그 봉의 (고+저+종)/3 | 그 봉에 새로 열린 포지션의 평균 가격 가정 |
| 청산가 | 롱 = 진입가×(1 − 1/배율 + MMR), 숏 = 진입가×(1 + 1/배율 − MMR) | |
| `BAND` | 10% | 지금 가격 위·아래 이 범위 안의 청산 물량만 센다 |
| `A_MIN` | 0.2 | 비대칭이 이보다 작으면 "신호 없음" |
| `HORIZON_H` | 24 | 맞혔는지 보는 시간 |
| `FEE_PCT` | 0.10 | 왕복 수수료(시장가 0.05% × 2) |

봉마다 순서대로:
1. **쓸기** — 이미 있던 묶음 중 롱 청산가 ≥ 그 봉 저가, 숏 청산가 ≤ 그 봉 고가인 것은 청산된 것으로 보고 지운다.
2. **줄이기** — OI 가 줄었으면 남은 묶음 전부(롱·숏)에 `OI_지금 / OI_직전` 을 곱한다.
3. **더하기** — OI 가 늘었으면 늘어난 만큼을 롱 묶음 하나·숏 묶음 하나로 더한다(계약마다 롱과 숏이 한 쌍). 배율 4개로 똑같이 나눈다. 새 묶음은 자기 봉에서는 쓸지 않는다.
4. 14일 넘은 묶음을 버린다. OI 가 빠진 봉은 직전 값 그대로(증감 0)로 보고 쓸기만 한다.

**매일 00:00 UTC**(23시 봉이 닫힌 뒤) 그 종가 `P` 에서:
- `UP` = 청산가가 `P` 초과 ~ `P×1.10` 인 숏 묶음의 금액 합, `DN` = 청산가가 `P×0.90` ~ `P` 미만인 롱 묶음의 금액 합.
- **비대칭 `A` = (UP − DN) / (UP + DN)**, −1 ~ +1. 합이 0이면 없음.
- 가설(자석): `A ≥ +0.2` → 24시간 뒤 **오름**, `A ≤ −0.2` → **내림**, 사이는 신호 없음.
- 성적 = 방향 × 24시간 수익률 − 0.10%. (종이 계산. 주문 없음.)

## 3. 반드시 같이 보는 대조군 (이 설계의 핵심)

롱과 숏은 항상 같은 양으로 생기므로, 추정 맵의 비대칭은 **"최근 가격이 어느 쪽으로 움직여 한쪽이 쓸려 나갔나"** 에서 나온다.
즉 `A` 는 "최근 14일 내렸으면 위쪽이 두껍다"와 거의 같은 말일 수 있다. 그렇다면 청산 맵은 새 정보가 아니다.
- **B14** = 지난 14일 수익률의 반대 방향, **B24** = 지난 24시간 수익률의 반대 방향. 청산 맵이 신호를 낸 같은 날·같은 코인에서 같은 식으로 성적을 낸다.
- `A` 와 지난 14일 수익률의 상관도 함께 적는다.
- 청산 맵 성적이 B14 보다 낫지 않으면 "가격 되돌림을 다르게 그린 것"으로 본다.

## 4. 선별 (과거 자료 시험) — 판단 기준을 먼저 적는다

자료: TradingView 로 받은 바이낸스 무기한 선물 1시간봉 + 미결제약정(`BINANCE:<코인>USDT.P`, `…P_OI`), 저장소 초단타 6코인(BTC·ETH·XRP·TRX·LINK·DOGE), 2026-01-01 ~ 지금. 앞 14일은 준비 구간.
(이 클라우드 세션은 거래소 직접 접속이 막혀 있다. 과거 자료 깊이가 1시간봉은 2026-01-01 부터라 약 300일이다.)

주 지표: **날짜별 성적**(그날 신호 낸 코인들의 수수료 뺀 성적 평균)의 평균과 t 값(같은 날 코인끼리는 함께 움직이므로 날짜 단위로 묶는다).

| 결과 | 조건 (전부 만족) | 다음 |
|---|---|---|
| 근거 있음 | t ≥ 2.0 · 앞 절반과 뒤 절반 둘 다 플러스 · B14 보다 나음(차이 평균 > 0) · `BAND` 5%·20% 변형도 같은 부호 | 순방향 관찰 트랙 구현(주문 없음, 채점만) |
| 근거 없음 | 위 중 하나라도 실패 | 검토 기록만 남기고 트랙은 만들지 않는다(P24·P27·P32 와 같은 처리). 사용자가 원하면 기록 전용으로만 |

- t ≥ 3 이 아니면 "약한 근거"라고 적는다(`docs/BACKTEST_OVERFITTING_REVIEW.md`).
- 반대 방향(청산 물량 적은 쪽으로 감)이 t ≤ −2 로 나와도 **채택하지 않는다.** 결과를 보고 방향을 고른 것이 되므로, 새 가설로 따로 등록해 순방향으로만 본다.
- 참고로만 적는 것(판단에 안 씀): 72시간 뒤 성적, `A` 3분위별 평균 수익률, BTC 단독 성적, 모형이 "쓸었다"고 본 물량과 실제 청산 체결량(`…P_LQSELL`·`…P_LQBUY`)의 상관.
- 과거 시험은 약한 근거다. 통과해도 실거래 제안이 아니라 순방향 기록의 시작이다.

## 5. 순방향 관찰 트랙 (선별 통과 시에만 구현)

- `liqmap.py` 가 매일 00:00 UTC 기준으로 6코인의 `A`·신호를 `liqmap.json`·`liqmap_history.jsonl` 에 적고, 다음 날 채점한다.
- 자료는 GitHub Actions 에서 열리는 공개 API(OKX 미결제약정 이력 등 — Actions `probe` 로 먼저 실호출 확인). 키 없음.
- 첫 판단: 순방향 채점 60일. 기준은 4절 표와 같은 틀(날짜별 성적 t, B14 대비). 판정기(`verdict.py`)·`criteria.json` 에는 넣지 않는다(기록 전용, P37 과 같은 급).
- 한 장 카드 `docs/cards/p38_liqmap.svg`, 현황판 카드는 병합 뒤 별도 PR.

## 6. 한계 (미리 적어 둔다)

- 레버리지 분포·유지증거금률은 가정이다. 실제 포지션은 아무도 공개하지 않는다(코인글래스도 같다).
- OI 증가분만 "새 포지션"으로 본다. 한 시간 안에 열리고 닫힌 포지션, 손바뀜(OI 변화 없는 거래)은 안 보인다.
- 한 거래소(바이낸스)만 본다. 화면의 5개 거래소 합과 숫자가 다르다.
- 약 300일·하루 1번 신호라 표본이 작다. t 2 는 20번에 1번 우연으로도 나온다.

### 모형 대조 (BTC, 7,297시간)

모형이 "쓸렸다"고 본 물량과 실제 청산 체결량의 상관: 롱 물량 vs 실제 매도 청산 0.652(순위 0.602), 숏 물량 vs 실제 매수 청산 0.664(순위 0.566).

오늘(11/15 00:00 UTC, BTC 64,130.5) 모형 값: 범위 20% 에서 위쪽 숏 $1,060M vs 아래쪽 롱 $182M(5.8배, 비대칭 +0.71) — 사용자 화면의 "위쪽이 약 4배"와 같은 모양이다. 범위 10% 는 $199M vs $161M(+0.10, 신호 없음), 5% 는 $82M vs $123M(−0.20).

### 해석

- **추정 맵 자체는 현실과 닮았다.** 실제 청산과 상관이 0.65 이고, 오늘 값도 코인글래스 화면과 같은 모양이다. 틀린 것은 맵이 아니라 "많이 쌓인 쪽으로 간다"는 **자석 해석**이다.
- 올해 자료에서는 자석 방향으로 매일 걸면 수수료 전에도 손해(−0.16%)였고, 적중률이 절반 아래(45.8%)였다. 특히 "위쪽 숏이 두껍다 → 오른다"가 더 나빴다(−0.53%).
- 이유(구조): 롱과 숏은 같은 양으로 생기므로 비대칭은 한쪽이 쓸려 나간 뒤에 생긴다. 위쪽 숏이 두껍다는 것은 대개 "최근 내려서 롱이 이미 청산됐다"는 뜻이다. 올해는 내린 뒤 더 내린 날이 많았다.
- BTC 단독 t −2.73 은 "반대로 걸면 된다"는 뜻이 **아니다.** 결과를 보고 방향을 고른 것이 되고, 6코인 묶음으로는 t −1.37 이라 4절의 반대 방향 기준(t ≤ −2)에도 닿지 않는다. 채택하지 않는다.
