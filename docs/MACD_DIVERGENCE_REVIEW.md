# MACD 다이버전스 검토 ("주가가 계속 오르는데 MACD 는 못 따라올 때", 2026-11-13, 제안함 P36)

출처: 사용자가 공유한 SNS 카드 1장 — 고점 1·2·3 이 높아지는데 MACD 고점은 낮아짐 → 경고 1단계(상승 여력 약화?) · 2단계(일부 차익실현) · 3단계(전량 매도 검토).
재현: `python scripts/macd_div_check.py` (표준 라이브러리만, 인터넷 불필요).
한 장 카드: [`docs/cards/p36_macd_divergence.svg`](cards/p36_macd_divergence.svg) — SPY 2025년 실제 4연속 다이버전스와 규칙대로 판 자리·되산 자리.

## 0. 한 줄 결론

**카드대로 팔면 손해가 더 많다.** 20개 시장(미국·한국·금·환율·코인 일봉 15 + 코인 4시간봉 5)에서 하락 다이버전스 뒤 수익은 평소와 구별되지 않고(|t|>3 0개), 코인 4시간봉은 오히려 평소보다 **더 올랐다**(+1.00%, t +2.75). 보유자가 신호마다 팔고 되사면 20곳 중 **12곳에서 매수보유보다 수익이 줄었다**(QQQ +1394% → +769%). 남는 쓸모는 하나 — 낙폭이 20곳 중 14곳에서 약간 줄었다(수익을 내주고 사는 보험).

## 1. 결과를 보기 전에 고정한 것 (스크립트 머리말과 같음)

| 항목 | 값 |
|---|---|
| MACD | 종가 EMA12 − EMA26, 시그널 EMA9 (가장 흔한 설정) |
| 고점·저점 | 앞뒤 5봉 중 최고 고가(최저 저가). 5봉 뒤 확정 — 미래 정보 없음 |
| 하락 다이버전스 | 새 고점 P2 와 직전 고점 P1(간격 5~60봉): 가격 P2 > P1, MACD P2 < P1 |
| 3단계 | P1 도 다이버전스였던 경우 = 카드의 "고점 3" |
| 변형 zero | MACD(P1) > 0 일 때만 (상승장 안의 다이버전스) |
| 상승 다이버전스 | 대칭(가격 저점↓, MACD 저점↑) — 카드는 말하지 않지만 같은 논리라 함께 잼 |
| 진입·청산 | 확정봉 다음 봉 시가 |
| 비용 왕복 | 코인 0.20%, 한국 개별주 0.25%(세금 포함), 지수·ETF·금·환율 0.05% |
| 자료 | 일봉 `data/bb_reentry/`(2010~2026-11-03, P27 과 같은 파일), 4시간봉 `data/macd_div/`(바이낸스 2024-01-01~2026-11-13) |

사후 추가(1차 결과를 본 뒤, 근거 약함): 다이버전스 뒤 10봉 안 MACD-시그널 교차로 "확인"한 변형, 중앙값 열.

## 5. 활용 방법 — 실데이터가 허락하는 범위

1. **매도 신호로 쓰지 않는다.** 2·3단계 모두 수익을 깎는다. 특히 미국 지수·코인 4시간봉.
2. **보험으로만 쓴다면 "절반"이 낫다.** 전량보다 수익 손실이 작고 낙폭 감소는 비슷하다(SPY −34→−25%). 단 16년 동안 수익 −72%p(SPY +581→+509%)를 낸 보험료다.
3. **숏 진입 근거로 쓰지 않는다.** 코인에서 수수료 뒤 건당 −1.3~−9.5%.
4. **남는 관찰 후보:** 미국 지수 상승 다이버전스 뒤 20일(+2.62%, 앞·뒤 절반 +3.06/+2.18, 30건). |t| 3 미만이고 결과를 보고 고른 것이라 근거가 아니다. 쓰려면 오늘 날짜로 얼려 순방향으로만 센다(P36 B안).

## 6. 검증 한계

- 외부 논문은 이번에 찾지 않았다(실데이터 측정 우선).
- 미국 ETF 가격은 배당 미포함 → 매수보유 기준선이 약간 낮다(카드에 유리한 쪽 오차인데도 카드가 졌다).
- 고점 정의(앞뒤 5봉)·간격(5~60봉)은 하나만 고정했다. 다른 값으로 여러 번 돌려 좋은 것을 고르면 과적합이 된다(BACKTEST_OVERFITTING_REVIEW).
- 4시간봉은 2년 10개월(2024~)뿐이고 그 기간 코인이 크게 출렁였다.
- 백테스트는 약한 근거(원칙). 트랙·규칙·`criteria.json` 변경 없음.
