## 0. 한 줄 결론

가격 모양으로 **방향**을 맞히려는 시도는 12종목·2시간봉·307일에서 전부 잡음이었다. 반면 **크기(앞으로 12시간이 얼마나 크게 움직일지)** 는 안정적으로 맞는다(상·하반기 모두). 그래서 v2 는 ① 크기 예측을 중심에 두고, ② 방향 예측은 고정 예측기 3개를 매일 채점만 하며(잡음을 넘을 때까지 매매에 안 씀), ③ 크기 예측을 기존 트랙의 **포지션 크기 조절기**로 쓰는 것을 목표로 한다. 예측을 "따로 매매"하는 게 아니라 **이미 있는 규칙을 더 잘 쓰게 하는 장치**다.

## 1. 지금 방식이 안 되는 이유 (실데이터)

| 시험 | 결과 |
|---|---|
| 닮은 과거 16변형, 6,576회 순방향 | 적중 50.0~52.1%, 잡음 바닥 95% 선 50.8%. 수수료 뒤 전부 마이너스 |
| 가격 변수 10개 선별 (아래 2절) | 방향 IC 최고 −0.07(24h 반전) 이나 규칙으로 만들면 수수료 뒤 −4.8bp, 상반기 +10.9 → 하반기 −28.0 |
| 요일·시각 효과 | 상·하반기 부호가 바뀜 — 잡음 |

공통 패턴: **상반기(1~6월)에 보인 것이 하반기(6~11월)에 사라지거나 뒤집힌다.** 이것이 `docs/BACKTEST_OVERFITTING_REVIEW.md` 가 경고한 "골라서 보면 맞아 보이는" 현상이다.

## 2. 무엇이 예측되는가 — 사전 선별 결과 (2026-11-05)

자료: 바이낸스 선물 12종목 2시간봉 2026-01-01~11-04. 변수마다 종목별 과거 300봉 3분위(미래 정보 없음), 12시간 간격 평가 503시점.

| 변수 | 방향 IC(전체/상반/하반) | 방향 결론 | 크기(\|r\|) 상관 |
|---|---|---|---|
| 24h 수익 r12 | −0.059 / −0.092 / −0.027 | 반전 기미 있으나 규칙화하면 비용 못 넘김 | 0.044 |
| 60봉 범위 위치 | −0.070 / −0.102 / −0.042 | 같음 | 0.076 |
| 상대강도 r12−BTC | −0.068 / **−0.146 / +0.009** | 상반기만 — 불안정 | 0.078 |
| 거래량 z | 0.010 | 없음 | **0.107** |
| 변동성비 rv12/rv60 | −0.015 | 없음 | **0.086** |
| 나머지(r3, r60, VWAP 이탈, BTC r12, 24h 전 같은 시각) | \|IC\| ≤ 0.05, 부호 불안정 | 없음 | 0.04~0.08 |

**크기 예측:** 최근 24시간 변동성(rv12) 상위 3분위일 때 12h 뒤 평균 \|수익\| **2.15%**, 하위일 때 **1.58%** — 비율 1.36, **상반기 1.44 · 하반기 1.41 로 안정.** 변동성은 뭉쳐 다닌다(잘 알려진 사실이고 여기서도 확인됨).

## 3. v2 구조 — 세 층

```
[자료]  OKX 2시간봉 12종목 (Actions 에서 OKX 는 열려 있음, turtle/reversal/retest 와 같은 경로)
   │
   ├─ ① 크기 예측기 (매일 09:18, 종목별)
   │     pred_abs = 과거 300봉에서 rv12 분위 → 그 분위의 12h |수익| 중앙값
   │     출력: 종목별 "앞 12h 예상 폭 %", 분위(상/중/하)
   │
   ├─ ② 방향 예측기 3개 (고정, 매일 기록·채점만)
   │     D1 24h 반전: r12 하위 3분위 → 상승 확률 p = 과거 300봉 그 분위의 상승 비율
   │     D2 상황 기반 닮은 과거: 모양이 아니라 (rv12 분위, r12 분위, BTC r12 분위) 가 같은 과거 구간의 12h 수익 분포
   │     D3 기준선: 과거 300봉 상승 비율 (= 아무 정보 없음. D1·D2 가 이것을 못 이기면 가치 0)
   │     출력: 종목별 p_up (0~1), 분포 상위25/중앙/하위25
   │
   └─ ③ 채점기 (다음 날 실행, 어제 예측 vs 실제)
         크기: 예측 분위별 실제 |수익| 평균 → 상위/하위 비율
         방향: 적중률, Brier 점수(= (p_up − 실제 상승)² 평균, 낮을수록 좋음), 잡음 바닥(무작위 p 500회)
         기록: forecast_history.jsonl 한 줄/일, 판정은 verdict.py 의 여섯 번째 트랙
```

**AI 는 어디에도 없다.** 세 층 모두 고정 산술이다(원칙 3). AI 의 자리는 이 코드를 쓰고·검산하고·이상을 보고하는 것.

## 4. 어떻게 수익에 연결되는가

예측 자체로 주문을 내지 않는다. 쓰임은 두 가지이고 **둘 다 규칙 변경이라 제안함을 거친다**(③ 판정 PASS 뒤에만).

1. **변동성 목표 크기 조절(vol targeting)** — 기존 트랙(초단타·추세전환 4H·급상승 패턴)의 종이 포지션 크기를 `목표 변동성 ÷ 예측 폭` 으로 조절. 크게 흔들릴 때 작게, 조용할 때 크게. 방향을 못 맞혀도 손익의 들쭉날쭉함(최대 낙폭)을 줄이는 것이 문헌과 여기 실데이터(비율 1.36) 모두에서 근거가 있는 유일한 쓰임이다.
2. **문지기(gate)** — 초단타 VWAP 되돌림은 폭이 커야 비용을 넘긴다. 예측 폭이 하위 분위이면 그날 그 종목 신호를 건너뛰는 변형을 `VARIANTS` 에 **추가만** 해서 나란히 기록.

방향 예측(②)은 60일 채점에서 D3 기준선과 잡음 바닥을 **둘 다** 넘을 때만 3번째 쓰임(방향 필터)을 제안할 수 있다. 못 넘으면 방향 예측은 기록을 멈추고 크기만 남긴다 — 변형을 더 늘리지 않는다.

## 5. 합격선 (사전 등록 — 결과 보고 고치지 않는다)

`criteria.json` 에 `forecast` 항목으로 봉인 예정. 기간 **60일**(예측 시점 120 × 12종목 ≈ 1,440건).

| 항목 | PASS | 비고 |
|---|---|---|
| 크기 | 예측 상위 3분위 실제 \|수익\| ÷ 하위 3분위 ≥ **1.20**, 앞 30일·뒤 30일 각각 ≥ **1.10** | 선별 1.36 보다 낮게 잡음(표본 밖은 줄어드는 게 보통) |
| 방향 D1·D2 | 적중률 > 잡음 바닥 95% 선 **그리고** Brier 가 D3 보다 **0.005 이상** 낮음, 앞·뒤 30일 모두 | 하나라도 미달이면 그 예측기 FAIL → 기록 중단 |
| 공통 | 자료 결손일 ≤ 6일 | 결손이 많으면 NOT_YET |

실력 0 일 때 PASS 확률(`scripts/overfit_check.py` 방식)은 구현 때 계산해 `interpretation` 에 적는다.

## 8. 하지 않는 것

- 가격 모양 닮은 과거(P27)를 되살리지 않는다. D2 는 "모양"이 아니라 "상황 분위" 기준이고, 기록·채점만 한다.
- 변수를 더 늘리지 않는다. 2절 10개 중 쓰는 것은 rv12·r12·BTC r12 세 개뿐. 새 변수는 제안함 → 다음 60일.
- 60일 전에 숫자를 보고 합격선·분위 기준·기간을 고치지 않는다.
- 방향 예측이 FAIL 이면 "조금만 바꾸면" 을 하지 않는다 — 크기만 남긴다.
- 예측으로 직접 주문하지 않는다(원칙 1). 쓰임은 4절 둘뿐.
