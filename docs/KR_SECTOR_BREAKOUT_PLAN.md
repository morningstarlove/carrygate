# 한국 주식 "거래대금 상위 → 업종 동조 → 패턴 돌파" 자동화 설계서

작성 2026-10-03. 출처: SNS 게시글 5단계(아래). 이 문서는 그 5문장을 **기계가 매일 똑같이 판정할 수 있는 규칙**으로 바꾸고,
이 저장소의 원칙(주문 없음·규칙 고정·수수료 후 성적·순방향 시험)에 맞춰 단계별로 만드는 계획이다.

> 1/ 오늘 많이 거래된 종목 100개를 본다. 2/ AI한테 같은 '섹터'끼리 묶어달라 한다.
> 3/ 같은 섹터의 종목들이 '한 번에' 같이 오른 곳을 찾는다. 4/ 그 종목들이 박스권·삼각수렴·깃발형·컵앤핸들이면 5/ 매수한다.

## 0. 먼저 솔직하게

- **"1달 2배"는 검증할 수 없다.** 게시글은 성적표(기간·종목·손절 포함)를 안 보여 준다. 우리는 **3년 백테스트 + 4주 순방향 기록**으로 직접 확인한 숫자만 믿는다.
- 전략 자체는 새로운 것이 아니다. **주도 업종(동반 상승) + 횡보 뒤 돌파 매수**는 오닐(CANSLIM)·미너비니(VCP)의 핵심이고, 한국 테마주 장세에서 실제로 자주 보인다. 다만 돌파 매매는 **승률 40~55%, 손실은 작게·이익은 크게**로 버는 구조라서 손절 규칙이 전부다.
- 사람이 차트를 "비슷하다"고 보는 건 주관이다. 아래는 그걸 **숫자 규칙**으로 고정한 것이고, 결과 보고 고치면 과최적화다(원칙 5).

## 2. 5단계를 규칙으로 바꾼 것 (고정값)

### 1단계 — 유니버스 (매일 15:45 KST, 장 마감 뒤)

- 한국 주식(KOSPI+KOSDAQ, ETF·ETN·스팩 제외) **거래대금 상위 100**. 거래량이 아니라 **거래대금**을 쓴다(저가주 왜곡 방지).
- 저장: `kr_sector.json` 의 `universe` (종목·업종·종가·등락·거래대금·3개월 고점 대비).

### 2단계 — 업종 묶기

- 1차: 데이터에 붙어 오는 `industry`(34개 수준)로 **결정적으로** 묶는다. 사람·AI 개입 없음, 매일 같은 결과.
- 2차(선택): 한국 테마(반도체 소부장·전력기기·조선·로봇 등)는 `industry`를 가로지른다. 하루 1회 Claude API(하위 모델, Sonnet/Haiku)에 상위 100 종목명을 주고 테마 라벨을 받아 `data/kr_themes.json` 에 **캐시**한다. 같은 종목은 다시 묻지 않는다. 1차 결과와 나란히 기록만 하고, 판정은 1차를 기본으로 한다. 1차와 2차 중 어느 쪽이 더 잘 맞는지는 순방향 기록이 알려 준다.

### 3단계 — "한 번에 같이 오른" 업종 (동조 점수)

업종 그룹이 다음을 **모두** 만족하면 그날 "동조" 로 표시한다.

| 조건 | 값 | 이유 |
|---|---|---|
| 상위 100 안의 그룹 종목 수 | ≥ 3 | 1~2개는 종목 뉴스지 업종 흐름이 아니다 |
| 당일 상승 종목 비율 | ≥ 60% | "같이" |
| 당일 등락 중앙값 | ≥ +2% | "오른" |
| 또는 5거래일 수익률 중앙값 | ≥ +5% | 하루 쉬어 가도 주도 업종은 유지 |

오늘 기준으로 전기제품·항공방산·특수화학·정유 가 해당, 반도체는 당일 조건 미달(주간 조건으로 해당).

### 4단계 — 패턴 판정 (일봉, 최근 120봉)

공통 전처리: ATR20(와일더), 20일 평균 거래량, 피벗 고점/저점(좌우 3봉).
공통 필터: 종가 ≥ 20일 이동평균, 거래대금 ≥ 100억, **당일 상한가(+29.5% 이상)면 제외**(다음날 시가 체결 불가 위험).
공통 돌파 확인: **종가 > 저항선** 그리고 **거래량 ≥ 20일 평균의 1.5배**. 종가 기준이라 장중 가짜 돌파를 거른다.

| 패턴 | 형태 조건 | 저항선 |
|---|---|---|
| **박스권** | 최근 15~40일 구간에서 폭(상단−하단)/상단 ≤ 25%, 상단 터치(고가 ≥ 상단×0.97) 2회 이상, 하단 터치 2회 이상, 구간 내 종가가 상단을 넘은 적 없음 | 구간 최고가 |
| **삼각수렴** | 최근 20~60일, 피벗 고점 2개 이상이 내려오고(기울기<0) 피벗 저점 2개 이상이 올라감(기울기>0), 마지막 폭 ≤ 처음 폭의 50% | 고점 추세선의 당일 값 |
| **깃발형** | 깃대 = 최근 25일 안에 10일 이하로 저점→고점 +20% 이상. 깃발 = 그 뒤 3~15일, 되돌림 ≤ 깃대 높이의 50%, 깃발 평균 거래량 ≤ 깃대 평균의 70% | 깃발 구간 최고가 |
| **컵앤핸들** | 컵 30~120일: 좌측 고점 → 바닥(깊이 12~35%) → 우측 고점이 좌측의 95~105%. 핸들 5~20일: 되돌림 ≤ 컵 깊이의 1/3 이고 ≤ 12% | 핸들 최고가 |

종목 하나가 여러 패턴에 걸리면 모두 기록한다(어느 패턴이 돈이 되는지 나중에 가른다).

### 5단계 — 매수·청산 (고정, 종이 매매 → 순방향)

| 항목 | 규칙 |
|---|---|
| 신호 | 3단계 동조 업종 **안의** 종목이 4단계 돌파 확인 → 그날 15:45 신호 |
| 진입 | **다음날 시가**. 슬리피지 0.3% 가정. 시가가 신호일 종가보다 +8% 이상 갭이면 포기(추격 금지) |
| 손절 | max(패턴 하단, 진입가 × 0.93) — 어떤 경우에도 −7% 넘게 안 잃는다 |
| 청산 | ① 손절 ② 10일 최저가 이탈(터틀식 추적) ③ 보유 20거래일 도달 — 셋 중 먼저 오는 것 |
| 수량 | 계좌 × 1% ÷ (진입가 − 손절가). `turtle.py` 와 같은 방식 |
| 동시 보유 | 최대 5종목, 같은 업종 최대 2종목 |
| 비용 | 증권사 수수료 0.015%×2 + 매도 거래세 0.15% + 슬리피지 0.3%×2 ≈ **왕복 0.8%** |
| 변형(나란히 기록만) | `hold_10`(보유 10일), `no_sector`(3단계 없이 패턴만 → 업종 동조가 진짜 효과가 있는지 대조군) |

규칙 고정일 `RULE_FIXED` 이후 신호만 순방향으로 센다(터틀과 동일).

## 4. 백테스트 설계 (마일스톤 12-3)

- 기간 3년(2023-10 ~ 2026-10), 일봉.
- 유니버스 재구성: 현재 거래대금 상위 300 종목의 3년 일봉을 받아, **매일 그날의 종가×거래량 상위 100** 을 다시 만든다.
  **한계(명시):** 그 사이 상장폐지·거래정지된 종목이 빠진다(생존 편향). 결과는 실제보다 **좋게** 나올 수 있으므로 순방향 기록이 진짜 시험이다.
- 자료는 `tests/fixtures/kr/*.csv` 로 저장해 인터넷 없이 재실행 가능하게 한다(터틀과 같은 구조).
- 보고 항목: 신호 수, 승률, 평균 손익비, 수수료 후 총수익, 최대낙폭, 평균 보유일, **패턴별·업종동조 유무별** 분해. 변형 `no_sector` 와 비교해 3단계가 실제로 보태는 게 있는지 본다.
- 합격선(미리 정함): 수수료 후 3년 누적 > 0, 최대낙폭 < 25%, 신호 ≥ 100건. 못 넘으면 규칙을 고치지 않고 **"이 규칙은 안 된다"** 로 기록한다.

**결과(2026-10-04):** 누적 +90.3% ○ / 매매 298건 ○ / 최대낙폭 25.5% × → **불합격**. 규칙은 그대로 두고 순방향으로 간다.
업종 동조를 뺀 대조군은 +29.1% / 낙폭 34.1% 라 3단계는 실제로 보탠다. 깃발형만 손실. 숫자는 `kr_backtest.json`, 해석은 `HANDOVER.md`.

## 7. 알아야 할 위험

- **테마주 급등락**: 돌파 다음날 −10%도 흔하다. 상한가 제외·갭 8% 포기·−7% 손절이 방어선이고, 이 셋은 사후에 풀지 않는다.
- **거래정지·상장폐지**: 한국 중소형주 특유. 거래대금 100억 필터가 일부 막지만 다 막진 못한다.
- **생존 편향**: 4절 참조. 백테스트 숫자를 그대로 믿지 않는다.
- **데이터 지연**: TradingView 일봉은 15분 지연. 장 마감(15:30) 뒤 15:45 실행이면 그날 봉은 확정이다.
- **한 달 2배 기대치**: 1% 위험·최대 5종목이면 한 달에 계좌의 몇 % 단위로 움직인다. 두 배가 되려면 위험을 10배 올려야 하고 그러면 한 번의 연속 손실로 계좌가 끝난다. 이 설계는 **살아남는 쪽**을 택했다.
