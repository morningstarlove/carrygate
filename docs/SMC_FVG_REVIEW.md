|---|---|
| 스윙 고점·저점 | 프랙탈: 좌우 2봉보다 낮은 저가/높은 고가. 오른쪽 2봉 마감 뒤 확정 |

| 손절: 스윕 저점 아래 | S 에 닿으면 손절(갭이면 시가) |
| (익절: 카드 빈칸) | 2R, 50봉 지나면 종가 청산. 같은 봉 손절·익절이면 손절 먼저, 체결 봉 익절은 안 셈 |

| 기준선 | 같은 시장 매수보유의 봉당 평균 × 보유 봉수 |

## 3. 카드의 주장별 판정

| 카드 주장 | 실데이터 | 판정 |
|---|---|---|
| 순서 Sweep → MSS → FVG 가 진입 근거 | 일봉 플러스는 매수보유 대비 마이너스(상승장 몫), 4시간·1시간 코인은 수수료 뒤 마이너스 | **근거 없음** |
| FVG 되돌림에서 롱 (기다려서 싸게) | FVG 를 기다린 쪽이 바로 진입보다 일봉 4군·4시간 모두 나쁨. 되돌림이 안 오고 가는 좋은 거래를 놓치고, 오는 거래는 약한 거래가 많다. 1시간봉만 반대(−0.16% 대 −0.28%, 둘 다 마이너스) | **반대로 나옴** |
| 스윕 저점 아래 손절 | 손절 비율 43~61%. 1시간봉은 R폭 1.7% 라 왕복 0.20% 가 R 의 12% | **위치는 명확, 단기봉에선 비용이 큼** |
| 스윕 확인을 엄격히(되찜 마감) | `strict` 가 일봉 미국·4시간 코인에서 더 나쁨 | **개선 없음** |
| 숏도 거울로 된다(카드엔 없음) | 4시간·1시간 코인 숏 −0.49%·−0.35% | **아님** |

**다중 비교 주의:** 21개 자료 × 6규칙 = 126번 시험. 가장 큰 t 는 +2.98(결과 보고 고른 칸), t > 3 은 0개. 묶음 최고(일봉 미국 `ce` t +3.17)도 매수보유 대비 +0.06% 라 상승장 몫이다. **결과를 보고 고른 것이라 근거로 쓰지 않는다**(P19·P27 과 같은 원칙).

## 4. 이 저장소와의 관계

- 구조는 추세전환 트랙 `reversal.py`(4시간봉: 하락 추세 → 구조 전환 → 눌림 진입)·급상승 패턴 `retest.py`(돌파 → 되돌림 재진입)와 같은 계열. 이미 순방향 기록 중인 트랙과 겹친다.
- 차이는 "스윕(직전 저점 깨고 되돌림)" 조건 하나인데, 이것을 넣은 쪽이 낫다는 근거가 없다. 새 변형은 더 추가하지 않는다는 원칙(10/9)도 있다.
