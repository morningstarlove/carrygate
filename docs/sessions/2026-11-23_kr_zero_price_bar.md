# 2026-11-23 한국 주식 돌파: 시가 0 봉으로 −100% 매매 3건 (데이터 사고) 수정

## 무엇이 보였나
- 11/23 대신 실행 결과 돌파 판정이 **FAIL** 로 바뀌었는데, 15번째 매매가 SK바이오팜 **−100%**(청산가 0원).
- 대조군(no_sector)도 대한항공·하이브가 같은 날 −100%. 모두 `exit: 0.0`, `why: stop`, `gap: True`.
- 수익 −5.55% → −19.34%, 대조군 −18.38% → −42.83% 로 튄 것은 이 세 건 때문.

## 원인
- `kr_ohlcv.py` 의 세 경로(야후·네이버 API·네이버 fchart)가 **종가가 0 이하인지만** 걸렀다. 시가(또는 저가)가 0 인 봉은 통과.
- 종이매매는 시가가 손절가 아래면 "갭 손절 = 시가에 판다"로 계산 → 시가 0 → 0원 청산 → −100%.
- 검산(`selfcheck.py`)도 청산가 0 을 잡지 못했다(갭 손절은 손절가보다 싸게 팔리는 게 정상이라).

## 수정 (규칙·합격선·잠금 변경 없음)
1. `kr_ohlcv._bad`: 값이 비었거나 시가·고가·저가·종가 중 하나라도 0 이하, 또는 고가 < 저가면 그 봉을 버린다. 세 경로 모두 적용. 버려진 날은 기존 빈 날 메우기(P15)가 다른 경로로 채운다.
2. `selfcheck.py`: 한국주식 매매 청산가가 0 이하면 빨간불.
3. 시험 `tests.test_kr_breakout.FetchMerge.test_zero_price_bar_is_dropped`.

## 판정에 미치는 영향
- 순방향 종이매매는 실행마다 봉에서 다시 계산하므로, 수정 뒤 재실행이 세 매매를 바른 값으로 다시 쓴다.
- 1승 14패 상태라 15번째가 이기든 지든 승률은 15% 미만 — 15건이 되는 날 FAIL 은 그대로다. 다만 FAIL 이 "가짜 −100% 매매"로 확정되면 안 되므로 바른 데이터로 다시 센다.
