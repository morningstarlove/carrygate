# 추세 전환 매매법 (4시간봉) 자동화 설계서

작성 2026-10-05. 출처: SNS 카드 "한 달 만에 시드 3배 만든 추세 전환 매매법" (아래 5문장 + 댓글 3개).
이 문서는 그 문장들을 **기계가 매일 똑같이 판정할 수 있는 규칙**으로 바꾸고, 이 저장소의 원칙(주문 없음·규칙 고정·수수료 후 성적·순방향 시험)에
맞춰 만든 기록이다. 코드: `reversal.py`, 결과: `reversal.json` / `reversal_history.jsonl`, 시험: `tests/test_reversal.py`.

> 1. 4시간봉을 켠다. 2. 고점이 계속 낮아지는 하락추세인지 본다. 3. 마지막 저점을 '안 깨고' 다시 올라오는지 본다.
> 4. 직전 고점을 거래량 터지면서 뚫는지 본다. 5. 뚫고 한 번 눌렸을 때 들어간다.
> (댓글) 핵심은 고점이 아니라 **저점**. 하락추세 = 저점이 계속 깨지는 것. 저점이 처음으로 안 깨지는 순간 누군가 밑에서 받친 것.
> (댓글) 거래량 없이 고점 뚫는 건 90% 가짜. 뚫는 날 거래량이 평소 **2배 이상**.
> (댓글) 손절은 간단. **쌍바닥 저점 깨지면 끝.** 시그널이 틀렸다는 뜻.
> (그림) 쌍바닥·역헤드앤숄더·추세선 돌파·저점 높이기 — 공통점: 저점이 더 이상 안 깨지고, 직전 고점을 뚫고 올라갈 때.

---

## 0. 먼저 솔직하게

- **"한 달 3배"는 검증할 수 없다.** 기간·종목·손절·레버리지가 없다. 우리는 **3년 백테스트 + 순방향 기록**으로 직접 확인한 숫자만 믿는다.
- 전략 자체는 고전이다. **하락추세의 첫 "높은 저점" + 목선(직전 고점) 거래량 돌파 + 되돌림 진입**은 다우 이론의 추세 전환 정의와
  와이코프의 스프링/테스트, 역헤드앤숄더 목선 돌파와 같은 것이다. 새로운 건 없고, 차트를 "비슷하다"고 보는 주관을 숫자로 고정하는 것이 전부다.
- 카드에는 **청산(이익 실현) 규칙이 없다.** 손절만 있다. 우리는 카드와 같은 논리("저점이 깨지면 추세 끝")를 연장해 **진입 뒤 생기는 저점마다
  손절선을 올리는 것**을 청산으로 삼았다. 목표가는 없다. 이것은 우리가 정한 것이지 카드의 주장이 아니다.
- 규칙 숫자(2배·12봉·30봉·120봉·피벗 3봉)는 결과를 보기 **전에** 정했고, 결과를 보고 고치지 않는다(원칙 5). 고치고 싶으면 `VARIANTS` 에 변형으로
  **추가**해 나란히 기록한다.

## 1. 5문장을 규칙으로 바꾼 것 (고정값, `reversal.py` 상단)

| 카드 | 규칙 | 상수 |
|---|---|---|
| 4시간봉 | 업비트 240분봉(UTC 정렬) · OKX 4H 봉. 미완성 봉 제외 | `BAR_MIN = 240` |
| 저점·고점 | **피벗**: 좌우 3봉보다 낮은 저가(높은 고가). 오른쪽 3봉이 닫혀야 확정(12시간 뒤) | `PIVOT_K = 3` |
| 하락추세 | 직전 120봉(20일) 안에서 가장 낮은 피벗 저점을 **바닥(L1)** 으로 본다. 바닥 바로 앞 피벗 저점 L0 가 바닥보다 높아야(저점이 깨지며 내려옴), 그리고 구간 시작~L0 의 최고가 > L0~L1 의 최고가(**고점 낮아짐**) | `LOOKBACK = 120` |
| 저점 안 깨고 올라옴 | 바닥 뒤 새로 확정된 피벗 저점 **L2 ≥ L1** (쌍바닥·역헤드앤숄더 오른어깨·저점 높이기 전부 여기에 든다) | — |
| 직전 고점 | **목선** = 바닥(L1)~L2 사이 최고가. 목선 − L2 ≥ ATR(20봉)×1 (너무 작은 구조 제외) | `MIN_HEIGHT_ATR = 1.0` |
| 거래량 터지며 뚫음 | L2 확정 뒤 30봉(5일) 안에 **종가 > 목선** 이고 그 봉 **거래량 ≥ 직전 20봉 평균 × 2**. 거래량 부족한 돌파는 가짜로 보고 무시(횟수만 센다) | `BREAK_WAIT = 30`, `VOL_MULT = 2.0`, `VOL_N = 20` |
| 뚫고 한 번 눌렸을 때 | 돌파 뒤 12봉(2일) 안에 저가가 **목선까지** 내려오면 **목선에 지정가 체결**(갭이면 시가). 눌림이 안 오면 안 들어간다(횟수만 센다) | `PULLBACK_WAIT = 12` |
| 손절 | **L2 아래로 저가** → 청산(스톱 체결, 슬리피지 0.05%). 돌파~체결 사이에 L2 가 깨져도 구조 무효 | `SLIPPAGE_PCT = 0.05` |
| 청산 (우리 연장) | 진입 뒤 확정되는 피벗 저점이 손절선보다 높으면 손절선을 그 저점으로 올린다(내리지 않음). 저점이 깨지면 나온다 | — |
| 수량 | 계좌 × 1% ÷ (진입가 − 손절가). 명목가 합계 ≤ 계좌 100%(레버리지 1배). 6개 코인이 한 계좌를 나눠 쓴다 | `RISK_PCT = 1`, `MAX_NOTIONAL_PCT = 100` |
| 수수료 | 업비트 0.05%, OKX 0.05% (지정가도 보수적으로 테이커 값) | `VENUES` |
| 방향 | **롱만** (카드가 롱 매매법). OKX 선물도 롱만 | `long_only` |
| 규칙 고정일 | **2026-10-05**. 이후 진입한 매매만 순방향 | `RULE_FIXED` |

**그림의 4가지 모양이 한 규칙으로 줄어드는 이유.** 쌍바닥(L2 ≈ L1), 역헤드앤숄더(L2 > L1, 목선 = 머리 뒤 반등 고점), 저점 높이기(L2 > L1 가 여러 번),
추세선 돌파(마지막 낮은 고점을 넘는 것 = 목선 돌파)는 모두 "저점이 안 깨지고 직전 고점을 넘는다"로 표현된다. 카드도 그렇게 적었다(공통점).

**변형 (`VARIANTS`, 나란히 기록만):**

| 이름 | 바꾼 것 | 무엇을 시험하나 |
|---|---|---|
| `no_vol` | 거래량 조건 없음 (돌파만) | "거래량 없는 돌파는 90% 가짜" 주장. 거래량 조건이 실제로 성적을 올리는가 |
| `break_entry` | 눌림을 안 기다리고 돌파 봉 종가에 진입(슬리피지 적용) | "눌렸을 때 들어가라" 주장. 눌림을 기다리면 놓치는 매매 vs 더 싼 진입가 |

## 2. 체결·집계 가정

- 봉 단위 처리. 같은 봉 안에서 체결과 손절이 같이 나오면 순서를 알 수 없어 **건너뛴다**(횟수 `ambiguous`).
- 피벗 확정 전(3봉) 에 이미 돌파·눌림이 지나갔으면 그 봉들에 되돌려 적용한다(놓치지 않되 미래 정보는 안 쓴다 — 확정 시점에 보이는 과거 봉만).
- 성적은 터틀과 같은 틀: 순수익·CAGR·최대낙폭·승률·손익비·평균 R·연도별, 보유 중 최대 유리폭과 **반납**(최고점에서 청산가까지 돌려준 폭).
- 구조 통계: 구조 수 / 가짜 돌파(거래량 부족) / 눌림 없음 / 진입 전 저점 이탈 / 만료 — "왜 안 들어갔나"를 센다.

## 3. 실데이터 백테스트 결과

업비트·OKX 4시간봉 6,600개(2023-10-01 ~ 2026-10-05), Actions 실행 #37301931766 으로 수집. 표와 해석은 **인수인계서 마일스톤 13** 에 있다. 요약:

| 한 계좌 6코인 | 기본 | `no_vol` | `break_entry` |
|---|---|---|---|
| 업비트 현물 | +148% / CAGR 35% / 낙폭 −9.9% / 151건 / 손익비 2.8 | +191% / 낙폭 −17.6% / 250건 | +147% / 낙폭 −13.1% / 224건 |
| OKX 선물 롱만 | +18% / CAGR 5.6% / 낙폭 −12.9% / 157건 / 손익비 1.3 | +47% / 낙폭 −18.4% / 302건 | +88% / 낙폭 −17.1% / 254건 |

- 같은 코인인데 거래소별 성적이 8배 차이, 매매 겹침 절반 이하 → **규칙이 봉 하나 차이에 민감**하다. 업비트 숫자는 BTC 한 시장·매매 한 건(+89%)에 기대고 있어 믿지 않는다.
- 거래량 2배 조건은 수익이 아니라 **낙폭과 매매 수를 절반**으로 줄이는 장치였다. 배수 1.5/2/3 에 매우 민감(업비트 +200/+148/+31%).
- 눌림 대기는 OKX 에서 손해(+18% vs 돌파 즉시 진입 +88%), 업비트에서는 차이 없음.
- 승률 34~37%, 매매 중앙값 −1%, 손익비로 버는 추세추종. 낙폭이 얕은 건 수량 규칙 덕이다.

## 4. 매일 하는 일

- `CARRYGATE daily` 워크플로에서 터틀 다음에 `python reversal.py` 가 돈다. 12개 시장의 4시간봉 3년치를 받아 백테스트를 다시 하고
  오늘 단계(`scan` 구조 없음 / `armed` 구조 확인, 돌파 대기 / `broken` 돌파 확인, 눌림 지정가 대기 / `long` 보유)와 가격(목선·손절)을 기록한다.
- 하루 1회 실행이라 **4시간봉 6개 중 마지막 완성 봉 기준**의 상태만 남는다. 실전에서는 4시간마다 봐야 한다 — 이 저장소는 판단만 기록한다(원칙 1).
- `python reversal.py --report` 로 단계 변화를 본다. 검산(`selfcheck.py`)이 실현 순수익 재계산·손절선(패턴 저점 이하로 못 내려감)·
  지정가 진입(목선 이하)·손절 체결가(패턴 저점 이하)를 대조한다.

## 5. 판단 기준 (미리 정함)

- 순방향 매매 **20건** 이 쌓이기 전에는 판단하지 않는다. 12개 시장 × 4시간봉이라 터틀보다 빨리 쌓일 수 있으나 구조 조건이 까다로워 월 수 건 수준으로 본다.
- 소액 실전 후보가 되려면: 순방향 20건에서 손익비 ≥ 1.5, 그리고 백테스트 3년 포트폴리오가 "그냥 보유"보다 **낙폭**에서 분명히 낫다(수익이 아니라 낙폭).
- 거래량 조건·눌림 조건의 가치는 변형 대비로 판단한다. 기본이 두 변형보다 나쁘면 카드의 주장이 코인 4시간봉에서는 틀린 것이다 — 그래도 기본 규칙은 안 고친다. 기록만 한다.
